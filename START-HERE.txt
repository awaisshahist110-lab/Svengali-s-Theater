Svengali's Theatre source files

This package contains the complete source code, game artwork, music and effects, database schema and migrations, tests, and a prepared GitHub Pages build.

The docs/ folder is the ready-to-publish website. Source files are included so you can edit and rebuild the game.

To host this prepared build on your GitHub repository:
1. Extract this ZIP.
2. Add the contents of the Svengali-s-Theater folder to your repository's main branch, preserving the folders.
3. Push to main. The included workflow (.github/workflows/pages.yml) turns GitHub
   Pages on by itself and publishes the docs/ folder. Watch it under the
   repository's Actions tab.

The GitHub Pages build is configured for:
https://awaisshahist110-lab.github.io/Svengali-s-Theater/

GitHub Pages serves the interface, artwork and audio. It cannot run a database, so
multiplayer needs a small API alongside it. That API is a Cloudflare Worker included
here, and you host it on your own free Cloudflare account:

  npm ci
  npx wrangler login
  npm run deploy:api
  npm run set-api-origin -- <the URL that prints>

Until you run those, multiplayer still calls the original hosted API at
https://svengalis-theatre.awaisshah-ist110.chatgpt.site/api/game
See "Self-hosting the multiplayer API" in README.md.

To rebuild the GitHub Pages files with Node.js 22.13 or newer:
  npm ci
  npm test
  npm run build:pages

See README.md for the game rules and development details.
